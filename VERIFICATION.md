# Верификация XBOX-Inspector 0.3.0

Дата проверки — 23 ноября 2026 г. Цель — Windows x64. Toolchain — Rust 1.100.0 windows-gnu, зависимости закреплены в Cargo.lock.

База — актуальный XBOX-Inspector.zip пользователя, 682 933 800 байт, 7 155 записей, SHA-256 указан в JSON. Исходники извлечены отдельно, кэш target/ и вложенные релизы не использовались для сборки. Архив пользователя и игровая папка читались без записи.

| Проверка | Наблюдение |
| --- | --- |
| cargo test --locked --workspace | 36 тестов прошло. |
| Заново собранный EXE из чистого исходного ZIP | Self-test 10/10. С MinGW понадобился каталог компиляции без кириллицы. |
| Запуск из распакованного Windows ZIP | Лаунчер в каталоге с пробелами и кириллицей открыл и закрыл 12 тестовых окон в скрытом режиме, по одному на сочетание четырёх локалей и трёх тем. Глифы проверены отдельно тестами шрифтов. |
| Матрица собственных входов | 70 из 100 сценариев выполнены, 30 отмечены как непрогнанные. Ограничения перечислены в реестре. |
| MCP stdio | Пять локальных проверок, включая перечисление, чтение и ожидаемую ошибку отсутствующего отчёта. |
| Ghidra | В 12.2 успешно обработан собственный тестовый PE. Хеш совпал, гостевой код не запускался. |
| C++ | Независимый эталон для пересечений в собственной выборке дал 12 покрытых байтов. |
| Статический проход | 22 RPF9, 57 RDS5, 357 115 дескрипторов, 515 Bink-записей. |
| Открытый поиск | 33 152 потока в четырёх проверяемых архивах. |
| Повторная проверка | 33 152 потока из дополнительных индексов и 25 встроенных проверок, всего 33 177 совпадений. |
| Независимая распаковка | Python zlib-ng независимо подтвердил длины, конец и SHA-256 всех 33 152 потоков. |

Предыдущий Rust-проход 0.2.0 нашёл 32 692 потока. Повтор базового debug-прохода из обновлённых исходников остановился на переходе через границу окна чтения. Исправленный обход нашёл на 458 потоков больше в data.rpf и на 2 больше в сюжетном архиве. Числа после исправления совпадают с прежними эталонами SimuXBOX по четырём архивам. В movies.rpf проверенные Bink-диапазоны в сумме занимают 8 831 336 892 байта (99,987% этого файла). Подтверждение относится к заголовкам и таблицам кадров. Нативное декодирование каждого кадра этим проходом не выполнялось.

Время на этой машине составило примерно 6,0 с для открытого прохода и 5,4 с для повторной проверки. Снимок содержал 143 файла, включая рабочие материалы в каталоге Ghidra. Полная контрольная сумма всех больших файлов не измерялась. Код загрузки игры не запускался. В конфигурации по-прежнему указан отсутствующий game_scarlett_master.exe. Для закрытых каталогов сохранён статус ENCRYPTED_OR_UNRESOLVED.
